This folder contains the implementation of the Persistent Homology Turbulence Index as described by Baitinger and Flegel, 2021.

Implemented by Vineel Pentrala

```datadownload.ipynb``` contains code to download the required data.

Once you have data, you can run ```phti.ipynb```. This notebook contains the main implementation of the Index, along with a couple of plots and tables. The last cell downloads the results into this folder, which must then be moved to /src/dashboard. The dashboard should then run successfully.
