# Investors Tab User Guide

## Overview

The Investors tab is a comprehensive module within the QWIM (Quantitative Wealth and Investment Management) financial dashboard application that provides complete investor management capabilities. This user guide explains how to use each subtab to manage personal information, assets, goals, and income for both primary investors and their partners.

## Getting Started

The Investors tab consists of four main subtabs, each designed to collect and manage specific aspects of your financial profile:

1. **Personal Info** - Demographic and personal information
2. **Assets** - Financial asset management across different account types
3. **Goals** - Financial goal setting and tracking
4. **Income** - Retirement income planning and management

## Personal Info Subtab

### Purpose
Collect and manage comprehensive personal information for both primary investors and their partners, including demographic data, risk tolerance, and retirement planning details.

### How to Use

#### Investor Primary Section
1. **Name**: Enter the full legal name (required field)
   - Must match official identification documents
   - Maximum 100 characters
   
2. **Current Age**: Set current age (18-100 years)
   - Default value: 60 years
   - Used for retirement calculations
   
3. **Retirement Age**: Plan when to retire (50-80 years)
   - Default value: 65 years
   - Determines retirement timeline
   
4. **Income Start Age**: When to begin receiving portfolio income (50-80 years)
   - Default value: 65 years
   - May differ from retirement age
   
5. **Risk Tolerance**: Select investment comfort level
   - Options: Conservative, Moderately Conservative, Moderate, Moderately Aggressive, Aggressive
   - Default: Moderate
   - Affects portfolio recommendations
   
6. **Gender**: Select gender identity
   - Options: Male, Female, Other, Prefer not to say
   - Used for personalized planning
   
7. **Marital Status**: Select current status
   - Options: Single, Married, Divorced, Widowed, Separated, Domestic Partnership
   - Affects tax calculations and planning

#### Investor Partner Section
Complete the same information for your partner if applicable. All fields are optional for the partner section.

#### Real-time Summary
The system automatically generates a comprehensive summary showing:
- Names and ages for both investors
- Risk tolerance levels
- Marital status
- Combined profile overview

### Best Practices
- Ensure all information matches official documents
- Update ages annually or set up automatic age progression
- Review risk tolerance annually or after major life events
- Keep marital status current for accurate tax planning

## Assets Subtab

### Purpose
Manage financial assets across different tax treatment categories for comprehensive portfolio tracking and planning.

### Asset Categories

#### Taxable Assets
- **Description**: Standard investment accounts subject to annual taxes
- **Examples**: Brokerage accounts, savings accounts, taxable investment portfolios
- **Tax Treatment**: Dividends and capital gains taxed annually

#### Tax Deferred Assets
- **Description**: Retirement accounts with tax-deferred growth
- **Examples**: 401(k), 403(b), Traditional IRA, pension plans
- **Tax Treatment**: Taxes paid upon withdrawal in retirement

#### Tax Free Assets
- **Description**: Accounts with tax-free growth and withdrawals
- **Examples**: Roth IRA, Roth 401(k), municipal bonds, HSA (for medical)
- **Tax Treatment**: No taxes on qualified withdrawals

### How to Use

#### For Each Investor
1. **Enter Asset Values**: Input current market values for each category
   - Use whole dollar amounts
   - Step increment: $1,000 for easy entry
   - Minimum value: $0
   
2. **Review Displays**: System shows formatted currency values in real-time

3. **Monitor Totals**: Each investor's totals calculate automatically

#### Combined Summary
The system automatically calculates:
- Combined totals by asset category across both investors
- Grand total of all assets
- Asset allocation overview

### Data Entry Tips
- Use current market values, not purchase prices
- Update quarterly or after major deposits/withdrawals
- Include all account types in appropriate categories
- Round to nearest $1,000 for simplicity

### Sample Entry
```
Investor Primary:
- Taxable Assets: $250,000 (brokerage account)
- Tax Deferred Assets: $400,000 (401k + Traditional IRA)
- Tax Free Assets: $75,000 (Roth IRA)

Investor Partner:
- Taxable Assets: $150,000 (savings + brokerage)
- Tax Deferred Assets: $200,000 (403b)
- Tax Free Assets: $50,000 (Roth IRA)

Combined Summary:
- Combined Taxable: $400,000
- Combined Tax Deferred: $600,000
- Combined Tax Free: $125,000
- Grand Total: $1,125,000
```
